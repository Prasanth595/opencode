Mặc dù OpenCode có thể chạy trực tiếp trên Windows, chúng tôi khuyến nghị dùng [Windows Subsystem for Linux (WSL)](https://learn.microsoft.com/en-us/windows/wsl/install) để có trải nghiệm tốt nhất. WSL cung cấp một môi trường Linux hoạt động liền mạch với các tính năng của OpenCode.

:::tip[Tại sao nên dùng WSL?]
WSL mang lại hiệu năng hệ thống tệp tốt hơn, hỗ trợ terminal đầy đủ và tương thích với các công cụ phát triển mà OpenCode dựa vào.
:::

---

## Thiết lập

<Steps>

1. **Cài đặt WSL**

   Nếu chưa cài, hãy [cài đặt WSL](https://learn.microsoft.com/en-us/windows/wsl/install) theo hướng dẫn chính thức của Microsoft.

2. **Cài đặt OpenCode trong WSL**

   Sau khi WSL đã được thiết lập, hãy mở terminal WSL của bạn và cài đặt OpenCode bằng một trong các [phương pháp cài đặt](/docs/).

   ```bash
   curl -fsSL https://opencode.ai/install | bash
   ```

3. **Dùng OpenCode từ WSL**

   Chuyển đến thư mục dự án của bạn (truy cập tệp Windows qua `/mnt/c/`, `/mnt/d/`, v.v.) rồi chạy OpenCode.

   ```bash
   cd /mnt/c/Users/YourName/project
   opencode
   ```

</Steps>

## Ứng dụng Desktop + máy chủ WSL

Nếu bạn muốn dùng ứng dụng OpenCode Desktop nhưng vẫn muốn chạy máy chủ trong WSL:

1. **Khởi động máy chủ trong WSL** với `--hostname 0.0.0.0` để cho phép kết nối từ bên ngoài:

   ```bash
   opencode serve --hostname 0.0.0.0 --port 4096
   ```

2. **Kết nối ứng dụng Desktop** với `http://localhost:4096`

:::note
Nếu `localhost` không hoạt động trong thiết lập của bạn, hãy kết nối bằng địa chỉ IP của WSL thay thế (từ WSL: `hostname -I`) và dùng `http://<wsl-ip>:4096`.
:::

:::caution
Khi dùng `--hostname 0.0.0.0`, hãy đặt `OPENCODE_SERVER_PASSWORD` để bảo mật máy chủ.
:::

```bash
OPENCODE_SERVER_PASSWORD=your-password opencode serve --hostname 0.0.0.0
```

## Web client + WSL

Để có trải nghiệm web tốt nhất trên Windows:

1. **Chạy `opencode web` trong terminal WSL** thay vì PowerShell:

   ```bash
   opencode web --hostname 0.0.0.0
   ```

2. **Truy cập từ trình duyệt Windows của bạn** tại `http://localhost:<port>` (OpenCode sẽ in ra URL)

Chạy `opencode web` từ WSL đảm bảo quyền truy cập hệ thống tệp và tích hợp terminal đúng cách, đồng thời vẫn truy cập được từ trình duyệt Windows của bạn.

## Truy cập tệp Windows

WSL có thể truy cập mọi tệp Windows của bạn qua thư mục `/mnt/`:

- Ổ `C:` → `/mnt/c/`
- Ổ `D:` → `/mnt/d/`
- Và những ổ khác...

Ví dụ:

```bash
cd /mnt/c/Users/YourName/Documents/project
opencode
```

:::tip
Để có trải nghiệm mượt mẹo nhất, hãy cân nhắc clone/sao chép repo của bạn vào hệ thống tệp WSL (ví dụ dưới `~/code/`) rồi chạy OpenCode tại đó.
:::

## Mẹo

- Hãy giữ OpenCode chạy trong WSL cho các dự án lưu trên ổ đĩa Windows - việc truy cập tệp sẽ liền mạch
- Dùng [tiện ích WSL của VS Code](https://code.visualstudio.com/docs/remote/wsl) cùng với OpenCode để có quy trình phát triển tích hợp
- Cấu hình và các phiên OpenCode của bạn được lưu trong môi trường WSL tại `~/.local/share/opencode/`
