:::note
Trên Windows, giá trị mặc định của `input_undo` và `terminal_suspend` khác nhau:

- `input_undo` mặc định là `ctrl+z,ctrl+-,super+z` khi không được cấu hình rõ ràng. Phím tắt `ctrl+z` được thêm vào vì terminal trên Windows không hỗ trợ POSIX suspend.
- `terminal_suspend` bị ép thành `none` vì terminal gốc của Windows không hỗ trợ POSIX suspend.
  :::

## Phím Leader

OpenCode dùng phím `leader` cho nhiều phím tắt. Điều này giúp tránh xung đột trong terminal của bạn.

Mặc định, `ctrl+x` là phím leader và nhiều thao tác yêu cầu bạn nhấn phím leader trước rồi mới nhấn phím tắt. Ví dụ, để bắt đầu một phiên mới, bạn nhấn `ctrl+x` trước rồi nhấn `n`.

Bạn không bắt buộc phải dùng phím leader cho các phím tắt của mình, nhưng chúng tôi khuyến nghị nên dùng.

Một số phím tắt điều hướng cố ý không dùng phím leader mặc định. Với các phiên subagent, giá trị mặc định là `session_child_first` = `<leader>down`, `session_child_cycle` = `right`, `session_child_cycle_reverse` = `left` và `session_parent` = `up`.

`leader_timeout` kiểm soát thời gian OpenCode chờ phím tiếp theo sau phím leader. Giá trị mặc định là `2000` mili giây.

## Giá trị phím tắt

Một chuỗi có thể chứa một phím tắt hoặc nhiều phím tắt phân tách bằng dấu phẩy. Bạn cũng có thể dùng một mảng cho nhiều phím tắt.

Với các trường hợp nâng cao, hãy dùng một đối tượng với `key`, `event`, `preventDefault` hoặc `fallthrough`.

```json title="tui.json"
{
  "$schema": "https://opencode.ai/tui.json",
  "keybinds": {
    "messages_copy": ["<leader>y", "ctrl+shift+c"],
    "input_paste": {
      "key": "ctrl+v",
      "preventDefault": false
    }
  }
}
```

---

## Tắt phím tắt

Bạn có thể tắt một phím tắt bằng cách thêm khóa đó vào `tui.json` với giá trị `"none"` hoặc `false`.

```json title="tui.json"
{
  "$schema": "https://opencode.ai/tui.json",
  "keybinds": {
    "session_compact": "none"
  }
}
```

## Phím tắt trong ô nhập của desktop

Ô nhập lời nhắc trong ứng dụng desktop của OpenCode hỗ trợ các phím tắt kiểu Readline/Emacs thông dụng để chỉnh sửa văn bản. Đây là các phím tắt tích hợp sẵn và hiện không thể cấu hình qua `opencode.json`.

| Phím tắt | Hành động                               |
| -------- | --------------------------------------- |
| `ctrl+a` | Di chuyển đến đầu dòng hiện tại         |
| `ctrl+e` | Di chuyển đến cuối dòng hiện tại        |
| `ctrl+b` | Lùi con trỏ một ký tự                   |
| `ctrl+f` | Tiến con trỏ một ký tự                  |
| `alt+b`  | Lùi con trỏ một từ                      |
| `alt+f`  | Tiến con trỏ một từ                     |
| `ctrl+d` | Xóa ký tự dưới con trỏ                  |
| `ctrl+k` | Xóa tới cuối dòng                       |
| `ctrl+u` | Xóa tới đầu dòng                        |
| `ctrl+w` | Xóa từ trước                            |
| `alt+d`  | Xóa từ tiếp theo                        |
| `ctrl+t` | Đảo vị trí hai ký tự                    |
| `ctrl+g` | Hủy popover / hủy câu trả lời đang chạy |

## Shift+Enter

Một số terminal không gửi phím bổ trợ kèm Enter theo mặc định. Bạn có thể cần cấu hình terminal để gửi `Shift+Enter` dưới dạng một escape sequence.

### Windows Terminal

Mở `settings.json` của bạn tại:

```
%LOCALAPPDATA%\Packages\Microsoft.WindowsTerminal_8wekyb3d8bbwe\LocalState\settings.json
```

Thêm nội dung sau vào mảng `actions` ở cấp gốc:

```json
"actions": [
  {
    "command": {
      "action": "sendInput",
      "input": "\u001b[13;2u"
    },
    "id": "User.sendInput.ShiftEnterCustom"
  }
]
```

Thêm nội dung sau vào mảng `keybindings` ở cấp gốc:

```json
"keybindings": [
  {
    "keys": "shift+enter",
    "id": "User.sendInput.ShiftEnterCustom"
  }
]
```

Lưu tệp rồi khởi động lại Windows Terminal hoặc mở một tab mới.
