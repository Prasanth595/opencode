SDK JS/TS của opencode cung cấp một client an toàn kiểu để tương tác với máy chủ.
Hãy dùng nó để xây dựng tích hợp và điều khiển opencode theo chương trình.

[Tìm hiểu thêm](/docs/server) về cách máy chủ hoạt động. Để xem các ví dụ, hãy xem các [project](/docs/ecosystem#projects) do cộng đồng xây dựng.

---

## Cài đặt

Cài SDK từ npm:

```bash
npm install @opencode-ai/sdk
```

---

## Tạo client

Tạo một instance của opencode:

```javascript
import { createOpencode } from "@opencode-ai/sdk"

const { client } = await createOpencode()
```

Thao tác này khởi động cả máy chủ lẫn client

#### Tuỳ chọn

| Option     | Type          | Mô tả                                | Default     |
| ---------- | ------------- | ------------------------------------ | ----------- |
| `hostname` | `string`      | Hostname của máy chủ                 | `127.0.0.1` |
| `port`     | `number`      | Cổng của máy chủ                     | `4096`      |
| `signal`   | `AbortSignal` | Tín hiệu huỷ thao tác                | `undefined` |
| `timeout`  | `number`      | Thời gian chờ khởi động máy chủ (ms) | `5000`      |
| `config`   | `Config`      | Đối tượng cấu hình                   | `{}`        |

## Cấu hình

Bạn có thể truyền một đối tượng cấu hình để tuỳ chỉnh hành vi. Instance vẫn dùng `opencode.json` của bạn, nhưng bạn có thể ghi đè hoặc bổ sung cấu hình trực tiếp:

```javascript
import { createOpencode } from "@opencode-ai/sdk"

const opencode = await createOpencode({
  hostname: "127.0.0.1",
  port: 4096,
  config: {
    model: "anthropic/claude-3-5-sonnet-20241022",
  },
})

console.log(`Server running at ${opencode.server.url}`)

opencode.server.close()
```

## Chỉ client

Nếu bạn đã có một instance opencode đang chạy, bạn có thể tạo một client instance để kết nối tới nó:

```javascript
import { createOpencodeClient } from "@opencode-ai/sdk"

const client = createOpencodeClient({
  baseUrl: "http://localhost:4096",
})
```

#### Tuỳ chọn

| Option          | Type       | Mô tả                             | Default                 |
| --------------- | ---------- | --------------------------------- | ----------------------- |
| `baseUrl`       | `string`   | URL của máy chủ                   | `http://localhost:4096` |
| `fetch`         | `function` | Cài đặt fetch tuỳ chỉnh           | `globalThis.fetch`      |
| `parseAs`       | `string`   | Cách phân tích response           | `auto`                  |
| `responseStyle` | `string`   | Kiểu trả về: `data` hoặc `fields` | `fields`                |
| `throwOnError`  | `boolean`  | Ném lỗi thay vì trả về            | `false`                 |

## Kiểu dữ liệu

SDK bao gồm các định nghĩa TypeScript cho toàn bộ kiểu API. Hãy import trực tiếp:

```typescript
import type { Session, Message, Part } from "@opencode-ai/sdk"
```

Mọi kiểu đều được sinh ra từ đặc tả OpenAPI của máy chủ và có trong <a href={typesUrl}>tệp kiểu dữ liệu</a>.

## Lỗi

SDK có thể ném lỗi mà bạn có thể bắt và xử lý:

```typescript
try {
  await client.session.get({ path: { id: "invalid-id" } })
} catch (error) {
  console.error("Failed to get session:", (error as Error).message)
}
```

## Kết quả có cấu trúc

Bạn có thể yêu cầu kết quả JSON có cấu trúc từ mô hình bằng cách chỉ định một `format` kèm JSON schema. Mô hình sẽ dùng công cụ `StructuredOutput` để trả về JSON đã được kiểm tra, khớp với schema của bạn.

### Cách dùng cơ bản

```typescript
const result = await client.session.prompt({
  path: { id: sessionId },
  body: {
    parts: [{ type: "text", text: "Research Anthropic and provide company info" }],
    format: {
      type: "json_schema",
      schema: {
        type: "object",
        properties: {
          company: { type: "string", description: "Company name" },
          founded: { type: "number", description: "Year founded" },
          products: {
            type: "array",
            items: { type: "string" },
            description: "Main products",
          },
        },
        required: ["company", "founded"],
      },
    },
  },
})

// Access the structured output
console.log(result.data.info.structured_output)
// { company: "Anthropic", founded: 2021, products: ["Claude", "Claude API"] }
```

### Các kiểu định dạng kết quả

| Type          | Mô tả                                                                |
| ------------- | -------------------------------------------------------------------- |
| `text`        | Mặc định. Response văn bản tiêu chuẩn (không có kết quả có cấu trúc) |
| `json_schema` | Trả về JSON đã được kiểm tra, khớp với schema đã cung cấp            |

### Định dạng JSON Schema

Khi dùng `type: 'json_schema'`, hãy cung cấp:

| Field        | Type            | Mô tả                                                       |
| ------------ | --------------- | ----------------------------------------------------------- |
| `type`       | `'json_schema'` | Bắt buộc. Xác định chế độ JSON schema                       |
| `schema`     | `object`        | Bắt buộc. Đối tượng JSON Schema định nghĩa cấu trúc kết quả |
| `retryCount` | `number`        | Tuỳ chọn. Số lần thử kiểm tra lại (mặc định: 2)             |

### Xử lý lỗi

Nếu mô hình không tạo được kết quả có cấu trúc hợp lệ sau tất cả các lần thử, response sẽ chứa một `StructuredOutputError`:

```typescript
if (result.data.info.error?.name === "StructuredOutputError") {
  console.error("Failed to produce structured output:", result.data.info.error.message)
  console.error("Attempts:", result.data.info.error.retries)
}
```

### Thực hành tốt nhất

1. **Cung cấp mô tả rõ ràng** trong các thuộc tính của schema để giúp mô hình hiểu cần trích xuất dữ liệu gì
2. **Dùng `required`** để chỉ định những trường bắt buộc phải có
3. **Giữ schema tinh gọn** - schema lồng nhau phức tạp có thể khiến mô hình khó điền chính xác
4. **Đặt `retryCount` phù hợp** - tăng cho schema phức tạp, giảm cho schema đơn giản

## API

SDK cung cấp toàn bộ API của máy chủ thông qua một client an toàn kiểu.

---

### Toàn cục

| Method            | Mô tả                                    | Response                             |
| ----------------- | ---------------------------------------- | ------------------------------------ |
| `global.health()` | Kiểm tra tình trạng và phiên bản máy chủ | `{ healthy: true, version: string }` |

---

#### Ví dụ

```javascript
const health = await client.global.health()
console.log(health.data.version)
```

---

### App

| Method         | Mô tả                                | Response                                    |
| -------------- | ------------------------------------ | ------------------------------------------- |
| `app.log()`    | Ghi một mục log                      | `boolean`                                   |
| `app.agents()` | Liệt kê tất cả các tác nhân khả dụng | <a href={typesUrl}><code>Agent[]</code></a> |

---

#### Ví dụ

```javascript
// Write a log entry
await client.app.log({
  body: {
    service: "my-app",
    level: "info",
    message: "Operation completed",
  },
})

// List available agents
const agents = await client.app.agents()
```

---

### Project

| Method           | Mô tả                  | Response                                      |
| ---------------- | ---------------------- | --------------------------------------------- |
| `project.list()` | Liệt kê tất cả project | <a href={typesUrl}><code>Project[]</code></a> |

---

#### Ví dụ

```javascript
// List all projects
const projects = await client.project.list()
```

### Path

### Config

| Method               | Mô tả                                    | Response                                                                                              |

### Phiên

| Method                                                     | Mô tả                              | Ghi chú                                                                                                                                                                                                                    |
| ---------------------------------------------------------- | ---------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `session.list()`                                           | Liệt kê các phiên                  | Trả về <a href={typesUrl}><code>Session[]</code></a>                                                                                                                                                                       |
| `session.get({ path })`                                    | Lấy phiên                          | Trả về <a href={typesUrl}><code>Session</code></a>                                                                                                                                                                         |
| `session.children({ path })`                               | Liệt kê các phiên con              | Trả về <a href={typesUrl}><code>Session[]</code></a>                                                                                                                                                                       |
| `session.create({ body })`                                 | Tạo phiên                          | Trả về <a href={typesUrl}><code>Session</code></a>                                                                                                                                                                         |
| `session.delete({ path })`                                 | Xoá phiên                          | Trả về `boolean`                                                                                                                                                                                                           |
| `session.update({ path, body })`                           | Cập nhật thuộc tính phiên          | Trả về <a href={typesUrl}><code>Session</code></a>                                                                                                                                                                         |
| `session.init({ path, body })`                             | Phân tích app và tạo `AGENTS.md`   | Trả về `boolean`                                                                                                                                                                                                           |
| `session.abort({ path })`                                  | Huỷ một phiên đang chạy            | Trả về `boolean`                                                                                                                                                                                                           |
| `session.share({ path })`                                  | Chia sẻ phiên                      | Trả về <a href={typesUrl}><code>Session</code></a>                                                                                                                                                                         |
| `session.unshare({ path })`                                | Ngừng chia sẻ phiên                | Trả về <a href={typesUrl}><code>Session</code></a>                                                                                                                                                                         |
| `session.summarize({ path, body })`                        | Tóm tắt phiên                      | Trả về `boolean`                                                                                                                                                                                                           |
| `session.messages({ path })`                               | Liệt kê tin nhắn trong một phiên   | Trả về `{ info: `<a href={typesUrl}><code>Message</code></a>`, parts: `<a href={typesUrl}><code>Part[]</code></a>`}[]`                                                                                                     |
| `session.message({ path })`                                | Lấy chi tiết tin nhắn              | Trả về `{ info: `<a href={typesUrl}><code>Message</code></a>`, parts: `<a href={typesUrl}><code>Part[]</code></a>`}`                                                                                                       |
| `session.prompt({ path, body })`                           | Gửi lời nhắc                       | `body.noReply: true` trả về UserMessage (chỉ ngữ cảnh). Mặc định trả về <a href={typesUrl}><code>AssistantMessage</code></a> kèm phản hồi của AI. Hỗ trợ `body.outputFormat` cho [kết quả có cấu trúc](#structured-output) |
| `session.command({ path, body })`                          | Gửi lệnh tới phiên                 | Trả về `{ info: `<a href={typesUrl}><code>AssistantMessage</code></a>`, parts: `<a href={typesUrl}><code>Part[]</code></a>`}`                                                                                              |
| `session.shell({ path, body })`                            | Chạy một lệnh shell                | Trả về <a href={typesUrl}><code>AssistantMessage</code></a>                                                                                                                                                                |
| `session.revert({ path, body })`                           | Hoàn tác một tin nhắn              | Trả về <a href={typesUrl}><code>Session</code></a>                                                                                                                                                                         |
| `session.unrevert({ path })`                               | Khôi phục các tin nhắn đã hoàn tác | Trả về <a href={typesUrl}><code>Session</code></a>                                                                                                                                                                         |
| `postSessionByIdPermissionsByPermissionId({ path, body })` | Phản hồi một yêu cầu cấp quyền     | Trả về `boolean`                                                                                                                                                                                                           |

---

#### Ví dụ

```javascript
// Create and manage sessions
const session = await client.session.create({
  body: { title: "My session" },
})

const sessions = await client.session.list()

// Send a prompt message
const result = await client.session.prompt({
  path: { id: session.id },
  body: {
    model: { providerID: "anthropic", modelID: "claude-3-5-sonnet-20241022" },
    parts: [{ type: "text", text: "Hello!" }],
  },
})

// Inject context without triggering AI response (useful for plugins)
await client.session.prompt({
  path: { id: session.id },
  body: {
    noReply: true,
    parts: [{ type: "text", text: "You are a helpful assistant." }],
  },
})
```

### Tệp

| Method                    | Mô tả                                    | Response                                                                                    |
| ------------------------- | ---------------------------------------- | ------------------------------------------------------------------------------------------- |
| `find.text({ query })`    | Tìm kiếm văn bản trong tệp               | Mảng các đối tượng khớp với `path`, `lines`, `line_number`, `absolute_offset`, `submatches` |
| `find.files({ query })`   | Tìm tệp và thư mục theo tên              | `string[]` (các path)                                                                       |
| `find.symbols({ query })` | Tìm symbol trong không gian làm việc     | <a href={typesUrl}><code>Symbol[]</code></a>                                                |
| `file.read({ query })`    | Đọc một tệp                              | `{ type: "raw" \| "patch", content: string }`                                               |
| `file.status({ query? })` | Lấy trạng thái của các tệp được theo dõi | <a href={typesUrl}><code>File[]</code></a>                                                  |

`find.files` hỗ trợ một vài trường truy vấn tuỳ chọn:

- `type`: `"file"` hoặc `"directory"`
- `directory`: ghi đè thư mục gốc project cho việc tìm kiếm
- `limit`: số kết quả tối đa (1–200)

---

#### Ví dụ

```javascript
// Search and read files
const textResults = await client.find.text({
  query: { pattern: "function.*opencode" },
})

const files = await client.find.files({
  query: { query: "*.ts", type: "file" },
})

const directories = await client.find.files({
  query: { query: "packages", type: "directory", limit: 20 },
})

const content = await client.file.read({
  query: { path: "src/index.ts" },
})
```
