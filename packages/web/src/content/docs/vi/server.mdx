Lệnh `opencode serve` chạy một máy chủ HTTP không giao diện, cung cấp một endpoint OpenAPI mà opencode client có thể sử dụng.

---

### Cách dùng

```bash
opencode serve [--port <number>] [--hostname <string>] [--cors <origin>]
```

#### Tuỳ chọn

| Cờ              | Mô tả                                        | Mặc định         |
| --------------- | -------------------------------------------- | ---------------- |
| `--port`        | Cổng lắng nghe                               | `4096`           |
| `--hostname`    | Hostname lắng nghe                           | `127.0.0.1`      |
| `--mdns`        | Bật khám phá mDNS                            | `false`          |
| `--mdns-domain` | Tên miền tuỳ chỉnh cho dịch vụ mDNS          | `opencode.local` |
| `--cors`        | Các origin trình duyệt bổ sung được cho phép | `[]`             |

`--cors` có thể được truyền nhiều lần:

```bash
opencode serve --cors http://localhost:5173 --cors https://app.example.com
```

---

### Xác thực

Đặt `OPENCODE_SERVER_PASSWORD` để bảo vệ máy chủ bằng HTTP basic auth. Tên đăng nhập mặc định là `opencode`, hoặc đặt `OPENCODE_SERVER_USERNAME` để ghi đè. Điều này áp dụng cho cả `opencode serve` và `opencode web`.

```bash
OPENCODE_SERVER_PASSWORD=your-password opencode serve
```

---

### Cách hoạt động

Khi bạn chạy `opencode`, nó khởi động một TUI và một máy chủ. TUI là client
giao tiếp với máy chủ. Máy chủ cung cấp một endpoint đặc tả OpenAPI 3.1.
Endpoint này cũng được dùng để sinh ra [SDK](/docs/sdk).

:::tip
Hãy dùng máy chủ opencode để tương tác với opencode theo chương trình.
:::

Kiến trúc này cho phép opencode hỗ trợ nhiều client và giúp bạn tương tác với opencode theo chương trình.

Bạn có thể chạy `opencode serve` để khởi động một máy chủ độc lập. Nếu bạn đang
chạy TUI của opencode, `opencode serve` sẽ khởi động một máy chủ mới.

---

#### Kết nối tới máy chủ đã có

Khi bạn khởi động TUI, nó gán ngẫu nhiên một cổng và một hostname. Thay vào đó, bạn có thể truyền các cờ [`--hostname` và `--port`](/docs/cli), rồi dùng chúng để kết nối tới máy chủ của nó.

Endpoint [`/tui`](#tui) có thể dùng để điều khiển TUI thông qua máy chủ. Ví dụ, bạn có thể điền sẵn hoặc chạy một lời nhắc. Thiết lập này được các tiện ích mở rộng OpenCode [IDE](/docs/ide) sử dụng.

---

## Đặc tả

Máy chủ công bố một đặc tả OpenAPI 3.1 có thể xem tại:

```
http://<hostname>:<port>/doc
```

Ví dụ, `http://localhost:4096/doc`. Hãy dùng đặc tả này để sinh client hoặc kiểm tra các kiểu request và response. Hoặc xem nó trong một trình khám phá Swagger.

### Tệp

| Method | Path                     | Mô tả                                    | Response                                                                                    |
| ------ | ------------------------ | ---------------------------------------- | ------------------------------------------------------------------------------------------- |
| `GET`  | `/find?pattern=<pat>`    | Tìm kiếm văn bản trong tệp               | Mảng các đối tượng khớp với `path`, `lines`, `line_number`, `absolute_offset`, `submatches` |
| `GET`  | `/find/file?query=<q>`   | Tìm tệp và thư mục theo tên              | `string[]` (các path)                                                                       |
| `GET`  | `/find/symbol?query=<q>` | Tìm symbol trong không gian làm việc     | <a href={typesUrl}><code>Symbol[]</code></a>                                                |
| `GET`  | `/file?path=<path>`      | Liệt kê tệp và thư mục                   | <a href={typesUrl}><code>FileNode[]</code></a>                                              |
| `GET`  | `/file/content?path=<p>` | Đọc một tệp                              | <a href={typesUrl}><code>FileContent</code></a>                                             |
| `GET`  | `/file/status`           | Lấy trạng thái của các tệp được theo dõi | <a href={typesUrl}><code>File[]</code></a>                                                  |

#### Tham số truy vấn của `/find/file`

- `query` (bắt buộc) — chuỗi tìm kiếm (khớp mờ)
- `type` (tuỳ chọn) — giới hạn kết quả ở `"file"` hoặc `"directory"`
- `directory` (tuỳ chọn) — ghi đè thư mục gốc project cho việc tìm kiếm
- `limit` (tuỳ chọn) — số kết quả tối đa (1–200)
- `dirs` (tuỳ chọn) — cờ cũ (`"false"` chỉ trả về tệp)
