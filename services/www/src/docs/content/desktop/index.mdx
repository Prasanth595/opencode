OpenCode Desktop and the web interface share the same GUI shell. Every workspace feature outside the core conversation shell ships as a built-in plugin that uses the GUI plugin SDK, `@opencode/plugin/gui`.

## Install

Download the latest OpenCode Desktop build for your platform from the [installation guide](/#desktop), or open the web interface from an existing CLI installation:

```bash
opencode pair
```

OpenCode Desktop manages its own local background server automatically and can also connect to remote servers over HTTP, [SSH](/desktop/ssh), or [WSL](/desktop/wsl).

## Built-in plugins

Every workspace tool, file previewer, and server connector in the GUI is a built-in plugin. You can inspect, reload, or disable any plugin from [**Settings > Plugins**](/desktop/plugins).

## Default shortcuts

Built-in and installed plugins register commands in the command palette (**Cmd+K** / **Ctrl+K** or **Cmd+Shift+P** / **Ctrl+Shift+P**) and in **Settings > Shortcuts**.

| Command ID | Action | Default shortcut | Slash command |
| --- | --- | --- | --- |
| `terminal.toggle` | Toggle terminal | `Ctrl+\`` | `/terminal` |
| `terminal.new` | New terminal | `Ctrl+Alt+T` | — |
| `terminal.close` | Close terminal (when focused) | `Cmd+W` / `Ctrl+W` | — |
| `browser.open` | Open browser | `Cmd+Shift+B` / `Ctrl+Shift+B` | — |
| `browser.reload` | Reload browser page | `F5` | — |
| `browser.address` | Focus browser address | `Cmd+L` / `Ctrl+L` | — |
| `details.toggle` | Toggle summary | `Cmd+Shift+Y` / `Ctrl+Shift+Y` | — |
| `btw.ask` | Ask a side question | — | `/btw` |
| `debug.toggle` | Toggle debug bar | — | — |
| `ssh.add` | Add SSH server | — | — |
| `pairing.open` | Pair device | — | — |
| `updater.check` | Check for Updates… | — | — |

## Build your own

You can extend OpenCode Desktop with your own panels, commands, settings pages, server sources, and main-process integrations. Ship them in a plugin package with a `./gui` export, and users add them with `plugins` in `opencode.json(c)`.
